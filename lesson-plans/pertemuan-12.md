3. **Penyajian 2 - Demo Custom Icon Set (35'):**
Membuat ikon (Telepon, Lokasi, Email) dari gabungan shape.

4. **Penyajian 3 - Praktik Merancang Pattern (35'):**
Membuat pattern vektor untuk latar belakang identitas visual.

5. **Kesimpulan & Penutup (65'):**
- **Summary:** Keseragaman gaya adalah kunci profesionalisme.
- **Aplikasi:** Kuis gaya ikon.
- **Evaluasi:** Jobsheet 12: Set Ikon.
